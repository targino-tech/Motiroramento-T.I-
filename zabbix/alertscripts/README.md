# Diretório de Scripts e Ações de Alerta do Zabbix (Alertscripts)

Este diretório contém os scripts executáveis acionados quando um evento ou alarme é gerado pelo Zabbix Server.

## Scripts Padrão e Uso
- Notificações customizadas via Webhook / Shell
- Disparadores para Telegram, Teams, Slack ou gateways SMS
- Ações de remediação remota
